# The scalar model

Students should copy and extract **`loop_sm_scalar_source.tar.gz`**, following
the manual commands in the main README. It extracts a directory named
`loop_sm_scalar`, which belongs inside MadGraph's `models` directory.

This archive contains the 24 `.py` and non-hidden `.dat` files from the original
`loop_sm_scalar_180521_withaa_py3.tar.gz`. Each included file is byte-for-byte
identical to its original. No particles, interactions or parameter definitions
have been changed. Old Python bytecode, pickled model caches, hidden temporary
restriction cards and editor backup files are omitted.

SHA-256 of the source-only archive:

```text
2cc30d49391240d2a4f80bcea5d259b3ce9aa19d81ab4e36c1c2d662026aba8a
```

The original archive is retained for provenance and for the optional instructor
installer. Its origin and checksum are recorded in
[docs/provenance.md](../docs/provenance.md).
